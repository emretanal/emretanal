# Emre Tanal sosyal bağlantı sayfası

## Kurulum
1. `assets/profile.jpg` dosyasını kendi profil fotoğrafınla değiştir.
2. `index.html` içindeki `KULLANICI_ADI` alanlarını gerçek kullanıcı adlarınla değiştir.
3. VS Code Live Server ile `index.html` dosyasını aç.

## Özgeçmiş
Özgeçmiş butonu başlangıçta görünmez.
`cv/emre-tanal-cv.pdf` dosyasını eklediğinde Live Server veya Vercel üzerinde otomatik olarak görünür.

## Vercel
Bu klasörü GitHub deposuna yükleyip Vercel'e import edebilirsin. Framework ayarı gerekmez; statik site olarak çalışır.
